# Unique Salon — web

Web de una sola página para **Unique Salon** (maquillaje profesional y uñas, Lloret de Mar).
HTML + CSS + JS sin dependencias; se publica tal cual en GitHub Pages.

## Archivos

| Archivo      | Qué contiene |
|--------------|--------------|
| `index.html` | Estructura y textos de la web |
| `styles.css` | Diseño (paleta dorado / taupe / crema, responsive) |
| `script.js`  | Menú móvil, pestañas de servicios, animaciones, enlaces |
| `config.js`  | **Datos de contacto** (Instagram y WhatsApp) — se cambian solo aquí |

## Datos pendientes de sustituir

Todo lo que aparece en *cursiva roja* entre `[corchetes]` es un marcador.

- [ ] **WhatsApp**: poner el número en `config.js` (`whatsapp: "34XXXXXXXXX"`). Mientras esté vacío, los botones de WhatsApp abren el chat de Instagram.
- [ ] **Teléfono** (sección Contacto).
- [ ] **Horario** de lunes a domingo.
- [ ] **Precios** de cada servicio.
- [ ] **Lista de servicios**: confirmar nombres (los de uñas y maquillaje son orientativos, deducidos del Instagram) y completar `[Otro servicio]`.
- [ ] **Opiniones**: sustituir por reseñas reales (Google, Instagram) con permiso.
- [ ] **Historia del salón** en "Sobre nosotras".
- [ ] **Código postal**: se ha puesto 17310 (Lloret de Mar); verificar.
- [ ] **Fotos**: las actuales son de [Unsplash](https://unsplash.com) (uso libre) y sirven de muestra. Sustituirlas por fotos propias del salón (portada, servicios, galería, sobre nosotras).
